# SQL for Data Analytics

This repository contains my structured learning and hands-on practice of SQL using PostgreSQL. It covers concepts from basics to advanced topics used in data analytics.

## Topics Covered

- Creating Databases and Tables  
- Inserting Data into Tables  
- Deleting Data and Dropping Tables  
- Data Types and Constraints  
- Updating Data  
- Altering Table Structures  
- Importing CSV Files  
- SQL Operators  
- Set Operators  
- Aggregate Functions  
- String Functions  
- Date and Time Functions  
- Conditional Functions  
- COALESCE Function  
- Window Functions  
- Joins  

## Tools Used

- PostgreSQL  
- pgAdmin  

## Purpose

- Strengthen SQL fundamentals  
- Practice real-world queries  
- Prepare for Data Analyst roles
